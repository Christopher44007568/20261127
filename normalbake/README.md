# normalbake

纯 Go 标准库实现的高低模法线烘焙，零外部依赖。

## 运行

```sh
go run .
```

程序内置生成测试资产：低模环面（含镜像 UV 补丁、深凹陷）与高模环面
（叠加衣褶波纹与硬边台阶），并导出 `low.obj` / `high.obj`。

## 功能

- 最近表面投射：沿低模插值法线双向投射，取最近命中（`MethodNearest`）
- 包围笼方向：从沿法线膨胀的笼点向 `-N` 投射（`MethodCage`）
- 切线空间输出：由 UV 梯度构建 TBN，支持镜像 UV 手性翻转
- 自遮挡检测：射线在到达高模表面前被其他低模几何阻挡时标记
- 零命中像素保持中性法线 `(128,128,255)`

## 输出

- `normalmap_nearest.png` / `normalmap_cage.png`：两种投射方向的切线空间法线贴图
- `diag_nearest.png` / `diag_cage.png`：诊断图（红=镜像 UV，蓝=自遮挡，绿=零命中，深灰=未覆盖）
- `normal_sphere.png`：法线贴图材质球预览
- `compare.png`：低模回贴法线贴图（左）与高模真实法线（右）对照

对比可见：包围笼法在凹陷与硬边处因射线方向错误捕获到错误表面
（法线贴图中出现异常色斑），最近表面投射则保持干净。
